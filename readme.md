# Nova Studio Website Starter

เว็บตัวอย่างแบบ static สำหรับเริ่มทำเว็บไซต์ได้ทันที ไม่ต้องติดตั้ง dependency

## ไฟล์หลัก

- `index.html` โครงหน้าเว็บและเนื้อหา
- `styles.css` สี ฟอนต์ layout และ responsive
- `script.js` เมนูมือถือและฟอร์มตัวอย่าง

## วิธีเปิดดู

ดับเบิลคลิก `index.html` หรือเปิดไฟล์ด้วย browser ได้เลย

## แก้เป็นเว็บจริง

- เปลี่ยนชื่อเว็บจาก `Nova Studio` เป็นชื่อของคุณ
- เปลี่ยนข้อความในแต่ละ section
- ปรับสีหลักใน `styles.css` ตรงตัวแปร `:root`
- ถ้ามีรูปหรือโลโก้ ให้ใส่ไว้ในโฟลเดอร์ `assets`
